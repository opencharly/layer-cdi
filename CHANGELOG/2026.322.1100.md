# 2026.322.1100 — fix(skills): make both skill files' frontmatter agree with their entities

Agent: charly (session lead, opencharly umbrella)

## Summary

Both of this repo's skill files carried a `description:` that differed from their `skill:` entity's inline `description:`, and the corpus generator hard-errors the **whole corpus** on a disagreement:

```
charly marketplace: skill "cdi-layer": the node's inline `description:` and its file's frontmatter disagree
```

That line is what `opencharly/marketplace`'s refresh is now failing on (dispatched run `44288442717`, 2026-11-18), after the first such defect was fixed in `opencharly/distro-cachyos#198/#199` and the run got one skill further. `cdi` disagrees identically and would have been the next day's failure, so both are fixed here rather than one per day.

Each file's `description:` is **generated from its entity** and the pair is then re-parsed and compared, so the two cannot drift by a character — which is the failure mode this PR removes. Frontmatter key order is preserved; the diff is 2 files, +10/−2.

## How tested

The generator's own comparison, run over every `skill:` node in this repo against its file — the same tree and commit, once with the change stashed and once applied:

```
$ git -C <worktree> stash      # pristine
before: entity == file ? False          # cdi-layer
$ git -C <worktree> stash pop  # change applied
2 entity/file pairs agree; 0 bad []
```

So the comparison fails without the change and passes with it. The repo's structural gate is green on the committed tree:

```
$ ./charly/bin/charly -C <worktree> box validate
charly box validate: OK — checked 7 candies, 6 distros, 7 builders; 0 warnings, 0 errors
```

End-to-end proof (the refresh going green and regenerating the corpus) cannot be produced from here: the generator's root is `opencharly/marketplace`'s refs list, which reaches this repo **transitively** through `distro-cachyos`'s composition at a **tag**, so a local run cannot see this branch. The first refresh after merge is that proof, and it is also the run that finally publishes the immich retirement's corpus consequence.
