version range: "every release BEFORE v2026.323.0124 strips with the over-broad
`libcuda*.so*`". A per-tag presence sweep over all 21 `layer-cuda` tags says
otherwise — **only `v2026.321.1520`** carries the prefix glob (2 occurrences);
the other 20 carry none. Of the 18 releases before the anchored `.0124`,
exactly one is over-broad and 17 have no `libcuda*` strip at all, so their
driver libraries survive and a red there is true for a different reason.

The comment now states that measured boundary and keeps the half that is
right: `v2026.323.0124` (layer-cuda#24) is the FIRST release whose strip this
assertion can twin. One file changed, +9 −5.
